	1. difference between varchar vs char
		As varchar is a dynamic memory updating also ** varchar - when memory plays crucial role 
								char - when we need fast execution **
	2. What are constraints
		constraints are set rules that applied on particular column or table in database to maintain data integrity and accuracy
		some of the SQL constraints:
		
			1. CHECK: this is conditional based constraint 
				eg: if we are storing the data from users form if the user is below age of 18 then it is invalid user 
					--->Age int Check(Age>18)
			2 NOTNULL: this constraint is used for  columns the values that should not be null means there should be a value
				eg Gender VARCHAR(10) NOT NULL
			3. UNIQUE: there should not be any duplicates in the column 
				eg: ID

**In SQL primary key constraints cannot be when it is connected to another table foreign key
